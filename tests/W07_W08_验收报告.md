## 七、过程中发现并修复的问题（如实记录）

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | **首次真浏览器验收只有 10/18**：`render()` 把传入的 `document`（`nodeType 9`）当成 DOM 元素读了 `ownerDocument`，值为 `null`，函数直接 `return false`，结果页 DOM 全空；但分享卡用的是同一份 `model`，所以卡片出图正常，形成「数据对、页面空」的假象 | 修 `render()`：先判断 `nodeType===9` 再决定 `doc` / `scope`；重跑 18/18 |
| 2 | **三条断言在空页面下会假通过**（R4 分数行空数组时循环不执行、R8 / R11 空文本自然不含禁词） | 加 `rows.length===5`、`text.length>100` 前置条件，杜绝空页面算通过 |
| 3 | 卡片台词按像素折行把「程序」拆成两行 | `wrapText()` 优先在中文逗号处断成两行（5 条官方卡片台词都带逗号），兜底仍按像素折行；另把台词上移 24px，拉开与徽章的间距 |
| 4 | `cardTextOf()` 把台词引号重复包了一层，日志里出现「「…」」 | 去掉重复引号；只影响验收日志文本，Canvas 实际绘制一直是单引号 |
| 5 | W06 验收 T8 断言「查看结果不跳转不产结果」在 W07 接线后必然失败 | 只改这一条为新口径，并在该行写明变更原因；W06 其余 11 项 + 4 项附加验证原样复跑 12/12 通过 |
| 6 | 首次生成的内联 SVG 带 `xmlns="http://www.w3.org/2000/svg"`，静态外链扫描把它识别成外部 URL | 内联 SVG 不需要 `xmlns`，删掉；零外部请求扫描干净 |
| 7 | W05 的 `.topbar` 与结果页 `.result-kicker` 都写了产品名，首屏看起来重复 | **未改**：属整体体验微调，留给你在完整流程验收时决定是否调整；不影响功能与红线 |
