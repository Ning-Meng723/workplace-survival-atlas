# 你的职场生存状态图鉴 · 网页 V1.0

一个**纯静态、零依赖、零后端**的趣味测试网页。用户在手机浏览器里答 20 题，前端本地算分，出结果页与分享卡片。
不登录、不支付、不收集个人信息，作答只保存在用户自己的浏览器里。

> 本仓库根目录 = 本文件所在目录（克隆后的 `web-v1/`）。
> 项目内部文档（项目总纲、任务表、决策记录、质量报告、旧版归档）**不在本目录内，也不上传**（决策 Q6）。

## 〇、公开测试版声明与免责

> **本仓库当前是公开测试版，不是正式发布版本。**

**关于「算得准不准」**

- 这是**趣味测试**，题目与判词都是原创娱乐内容，**没有经过心理学量表的编制与验证流程**。

- 20 题答案只写在你自己浏览器的 `localStorage`（键名 `atlas.quiz.v1`），刷新与关闭都不丢，清缓存即消失。

## 二、数据权威关系（只有一份真相）

| 内容 | 唯一权威 | 说明 |
| --- | --- | --- |
| 题目 / 选项 / `option_id` / `score` / 版本号 | `20-测试内容/题库.json`（项目内） | 本仓库 `data/题库.json` 是它的**逐字节副本**，禁止直接改 |
| 计分算法 / 物种匹配 / 并列 / 整体状态 / 副称号 | **本仓库 `docs/产品规则说明书_V1.0.md`** | 实现文件 `js/scoring.js`，母版 `tests/参考实现/计算核心.js` |
| 结果文案（台词 / 判词 / 建议 / 副称号解释 / 声明） | `20-测试内容/结果文案规范.md`（人工编辑源） | 本仓库 `data/结果文案.json` 由脚本生成，**禁止手工编辑** |
| 分享卡片视觉与卡片台词 | `20-测试内容/分享卡片设计规范.md`（人工编辑源） | 同上，卡片字段一并写进 `data/结果文案.json` |

### 改内容的标准流程（照做，别跳步）

**改题目 / 分值**
1. 改 `20-测试内容/题库.json`；
2. 按 `20-测试内容/题库版本记录.md` 升版本号；
3. 跑 `node "70-质量检查/版本快照.js" --update`；
4. 重新复制到本仓库 `data/题库.json`；
5. 跑 `node "tools/校验题库同步.js"`，必须全绿。

**改文案**
1. 只改 `20-测试内容/结果文案规范.md` 或 `分享卡片设计规范.md`；
2. 跑 `node "tools/生成结果文案.js"`；
3. 跑 `node "tools/校验结果文案.js"`，必须全绿；
4. **永远不要**手改 `data/结果文案.json`。

## 五、计分模块怎么用（浏览器 / Node 同一份文件）

```html
<!-- 浏览器：挂到 window.WorkplaceScoring -->
<script src="./js/scoring.js"></script>
```

```js
// 浏览器：题库 + 作答 → 结果对象（内部按 option_id 查分）
const bank = await fetch('./data/' + encodeURIComponent('题库.json')).then(r => r.json());
const result = window.WorkplaceScoring.scoreBank(bank, { Q01: 'Q01-O3', /* … 共 20 题 */ });
```

```js
// Node：同一份文件，CommonJS 直接 require
const scoring = require('./js/scoring.js');
const result = scoring.scoreBank(bank, answers);
```

**红线**：取分只认 `option_id`。不看 A/B/C/D、不看显示顺序、不看选项文字。
选项显示顺序打乱，结果必须完全不变。

**结果页模块**（`js/result.js`，浏览器挂 `window.WorkplaceResult`）：

```js
const model = window.WorkplaceResult.buildModel(result, copyJson); // 纯数据，不算分、不写文案
window.WorkplaceResult.render(model, document);                     // 填进结果页 7 模块骨架
window.WorkplaceResult.drawCard(model, { canvas }, info => { /* info.dataUrl 是 1080×1440 PNG */ });
```

- `buildModel` 只吃 `scoring.js` 的结果对象与 `data/结果文案.json`；槽位只认 6 个已定义槽位，`{最高维}` / `{最低维}` 填**维度名称**（N12 口径）。
- `radarSvg()` 的顶点半径与分数条数字都来自同一份 `model.dims`，两处 `data-value` 可直接比对（验收 R3）。
- `drawCard()` 的台词取 `台词_卡片_*`，不取结果页台词；卡片不画二维码、不画五维数字、不画雷达图。
